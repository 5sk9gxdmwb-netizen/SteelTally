## 步骤 1：创建 GitHub Release

浏览器打开：

https://github.com/5sk9gxdmwb-netizen/SteelTally/releases/new

填写：
- **Choose a tag**：输入 `v1.0.0`，点 "Create new tag on publish"
- **Target**：`main`
- **Release title**：`SteelTally v1.0.0`
- **Describe this release**：

```
SteelTally 表格算量首个正式版本。

功能：
- 标准型材库查询与截面特性计算
- 非标截面参数化计算（H型、圆管、箱形、圆钢、角钢、钢板）
- 父子构件层级录入，工程保存/重开
- Excel（三张表）与 PDF 报表导出、打印预览
- 浅色/深色主题，内嵌图标与四页离线帮助
- 单文件静态程序，仅依赖 Windows 系统 DLL
- 内置更新模块（当前未配置更新源，显示"未配置更新源"）

文件：gjg_table_qty.exe（58,834,192 字节）
SHA256：171c91a7eb6ba06d049231b099acd104c2a648a76b2b7114fbbd284a72b7a291

已知边界：独立机器验收待执行；未做 Authenticode 签名；Qt 静态链接的 LGPLv3 发行义务需按 distribution-materials/README.md 交付。
```

- **Attach binaries**：上传 `E:\表格算量\releases\v1.0.0\gjg_table_qty.exe`
  - 注意：文件名必须保持 `gjg_table_qty.exe`，否则清单 URL 不匹配
- 点击 **Publish release**

## 步骤 2：验证下载地址

发布后在 PowerShell 执行：

```powershell
curl.exe -sI "https://github.com/5sk9gxdmwb-netizen/SteelTally/releases/download/v1.0.0/gjg_table_qty.exe" | Select-String "HTTP|content-length|location"
```

应返回 `HTTP/1.1 302`（跳转到对象存储）或 `200`，`content-length` 为 58834192。

## 步骤 3：托管签名清单

清单需通过 HTTPS 可直接读取。推荐 GitHub Gist（最快）：

1. 浏览器打开 https://gist.github.com/
2. Filename 填 `manifest.json`
3. Content 粘贴 `E:\表格算量\releases\v1.0.0\manifest.json` 的全部内容（单行 JSON）
4. 选 **Create public gist**
5. 点 **Raw** 按钮，复制地址栏 URL，形如：
   `https://gist.githubusercontent.com/5sk9gxdmwb-netizen/<id>/raw/<hash>/manifest.json`

把该 URL 发给我，我用它构建配置了更新源的客户端。

## 步骤 4：构建带更新源的客户端（我来做）

拿到清单 URL 后执行：

```powershell
.\build-static.ps1 `
  -QtPrefix "E:\SteelTallyToolchain\static-6.8.3-20261110-101215\install" `
  -CMake "E:\SteelTallyToolchain\official-20261110-094827\cmake-3.31.8-windows-x86_64\extracted\cmake-3.31.8-windows-x86_64\bin\cmake.exe" `
  -UpdateUrl "<gist raw URL>" `
  -UpdatePublicKeyFile "C:\SteelTallyKeys\update-public-key.b64"
```

## 密钥保管提醒

- 私钥 `C:\SteelTallyKeys\update-private-key.xml` 是唯一签名凭据
- 丢失后无法为已发布客户端推送更新（客户端只信任该公钥）
- 建议另存一份到离线介质；不要放入 Git 仓库或云同步目录
