下载在 E:/SteelTallyToolchain 的独立时间戳目录进行；每个文件单独目录。manifest.json 记录 URL、文件大小、SHA256、curl 退出码。SHA256 本地记录用于后续一致性核对，不能冒充已经与官方发布校验表核对。Qt 官方下载入口可能重定向到分发镜像，curl 保持 HTTPS 证书校验。

新增 build-static.ps1：要求静态 Qt prefix 和明确的 CMake/Ninja 路径，使用新建 ASCII staging；仅成功后发布到 release-static，既有产物归档“旧版可删”。源码复制到 staging，构建保留对象文件与链接材料。

新增 verify-static.ps1：检查 PE 导入表排除 Qt/MinGW 外置运行库，将主 EXE 单独复制到新目录，清理 Qt 插件变量与开发 PATH，运行现有计算/交互/帮助自测。它仍属于本机隔离验证，不替代独立 Windows 机器验收。两脚本已做 PowerShell 语法检查；尚未声称实际静态构建成功。

CMake 改用 qt_add_executable/qt_finalize_executable，静态 Qt 时明确导入 Windows、offscreen、SVG image/icon 插件。插件目标与构建参数须等实际静态 SDK 生成后验证。原 CMake 文件已备份在“旧版可删/before-static-20261110-094927”。现有动态构建脚本不受 CMake 调整影响。
