## 关键技术

- C++17、Qt 6.8.3 Widgets、Svg、PrintSupport；现有工具链为 MinGW 13.1。
- 目前原生 Qt 表格已经有独立 `main.cpp` 入口，可直接运行，但仍需外部 Qt DLL、插件及 assets，尚不是目标单文件。
- 用户选择 A 方案：静态链接 Qt，图标/皮肤/型材库/帮助资源通过 qrc 内嵌。静态 Qt 构建、插件和许可材料尚未落实。

## 当前数据、计算能力与准确性

本次直接读取 `unified_sections.json` 得到：**3,711 条，19 个类别，906 条缺少面积系数**。
历史合库记录：3,897 输入，186 项合并；181 组重量/面积系数存在差异，以新版原生库为主并保留冲突记录。

当前程序与型材数据的关系：

- 启动从外置统一 JSON 加载到内存并建立索引；正常运行并不是在线请求第三方软件。
- 标准件采用所选标准版本/规格的单位重量和面积系数；相同名称的不同标准版次不能随意合并。
- 每行可保存已采用系数、来源、单位和尺寸快照。当前 `calc.h` 优先使用快照，缺少时查库；人工重量/面积覆盖仍有优先级。
- 长度以 mm 输入，换算到 m；线密度项按 kg/m 与 m²/m 计算；面密度项还需要实际宽度，不能仅靠长度。
- 非标支持焊接 H、圆管、方矩管/箱形、圆钢、角钢、钢板六类几何计算；保留原有其他兼容算法和参数构件。
- 已有“采用结果并开启实时联动”、人工覆盖保护、撤销本次计算；切行后停止对旧行回写。
- 规格无效或数据缺失时应明确报缺，不允许静默算零，也不能编造面积。
- 已有未定义面积的标准记录目前无法自动写回完整重量/面积结果；后续若要支持重量单独可用，应显式设计状态与汇总/导出规则，不能默默放开。

用户要求准确，不能将“已有库”“历史测试通过”表述为绝对准确认证。当前未逐本核验来源标准，906 条缺面积及181组冲突仍是实际边界。

建议的验收依据：每条计算可查标准/版次、规格、单位、系数、公式与面积口径；标准值冲突可追溯；尺寸合法性、数量/父构件倍数、单位换算与舍入规则一致；对标准样例与独立几何样例进行定向验证。
无需重做已撤销的旧工程对算。

非标面积口径必须保留说明：纵向面积一般不计端面、切口及连接扣除；钢板按双面大面，不计侧边和孔洞；圆角的输入与假设不能隐藏。标准件按条目记载的口径，不能混用为同一种涂装面积。
