# 独立版发布条件

截至 2026-11-10，完整项目已迁移，公共资源内嵌已验证。当前开发版本继承原生表格 1.0.3；正式独立版 1.0.0 编号尚未启用。

## 静态构建

现有 C:/Qt/6.8.3/mingw_64 是 shared 构建，lib/Qt6Core.prl 亦明确 QMAKE_PRL_CONFIG = shared。不能将 libQt6Core.a 文件名当作静态 Qt 证据，它在当前安装中属于动态库的链接材料。

下一次构建准备需要可核验来源的 Qt 6.8.3 源码或静态 SDK、CMake/Ninja 等工具，并验证 Windows 平台插件、SVG、图像、字体、打印和 PDF。当前未下载来源不明的静态库，也未接受尚未核验的许可条件。

用户选择单文件分发与静态 Qt；最终许可材料仍需匹配实际 Qt 授权方式。使用开源 Qt 静态链接时，需核对对应模块许可、源代码与重新链接材料的交付义务；未在本轮把这部分标记为完成。

## 更新发行

尚无发布服务器、版本清单 URL、签名私钥或受信公钥。客户端不包含私有仓库令牌。当前界面如实显示“未配置更新源”，检查按钮仅说明配置状态。

完整更新模块仍需实现：HTTPS 清单、版本比较、整包下载、大小与 SHA256 校验、受信签名校验、保存提示、退出后替换、重启、失败回滚。不能仅凭从同一服务器下载的哈希判定发布者可信。没有这些步骤时，不得将检查按钮称为已实现自动更新。

## 验收

最终验证必须使用无开发 Qt 的独立 Windows 环境，证明单 EXE 启动、空白工程、新工程保存/重开、计算、主题、帮助、Excel、PDF、打印预览。当前本机隔离目录验证只证明内嵌资源与已部署动态依赖可用，不替代该项。

发布前保留用户工程、设置和企业覆盖数据；原始桌面软件与原始源码不删除。替换前备份，退役产物归档“旧版可删”，由用户手动删除。
