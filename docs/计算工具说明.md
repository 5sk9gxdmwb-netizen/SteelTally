# 独立计算工具（calculationtools）

日期：2026-11-11。源码：`table_qty/src/calculationtools.h/.cpp`，自检驱动：`table_qty/tests/calculationtools_check.cpp`，期望值脚本：`table_qty/tools/calculationtools_expected.py`。

## 范围与诚实边界

- 工具只做算术，不读写工程、不联网、不依赖其他程序；结果仅是“按所填数据的算术值”。
- 界面分组与字段参照用户给出的参考软件截图，**未运行、未反编译参考软件，也未与其输出逐项比对**；本实现不是参考软件的复刻，不声称恢复其私有源码或算法。
- 所有几何量、密度、系数都必须由用户填写（密度 7850、弹性模量 206000 为界面上可见的预填值，可改）。缺失、非数、负数、不允许的 0 一律报错，不静默补默认值。
- 不内置任何规范取值表（荷载、栏杆荷载、摩擦面系数、预拉力、挠度限值、强度设计值），不输出“符合/不符合规范”结论；只给 σ/f、δ/L 等算术比值。螺栓公式 `Nv=0.9·k·nf·μ·P` 是 GB 50017 表达式的形式，**未对照标准原文核验**。

## 接口（主窗口接入用）

```cpp
#include "calculationtools.h"
QWidget* createCalculationTool(int kind, QWidget* owner); // kind: 0 面积重量 1 围护板 2 曲线构件 3 螺栓抗滑移 4 楼梯栏杆
bool runCalculationToolChecks(QString* error, const QString& outDir);
```

- 返回非模态 `QDialog`（父为 owner，关闭即删除），由调用方 `show()`。
- 无 `Q_OBJECT`，不需要 moc；新增 `src/calculationtools.cpp` 一个编译单元，只依赖 Qt Widgets。
- 菜单接入、CMake、`--selftest` 挂接由主会话负责（本任务未改 main.cpp、CMake、tableinputpanel、section*、更新/构建脚本）。

## 工具与公式

| 工具 | 子项 | 公式 / 说明 |
|---|---|---|
| 面积重量（8） | 自定义展开面积 | V=A·t/1000，W=V·ρ |
| | 钢板/花纹板 | W=L·B·t·ρ + 面积×“花纹附加”（产品标准值由用户填，0=不计） |
| | 圆管 | A=π[D²−(D−2t)²]/4 |
| | 方管 / 矩形管 | A=HB−(H−2t)(B−2t)−(4−π)[R²−(R−t)²]，R=0 为尖角（与截面库非标管同式） |
| | 角钢 | A=(a+b−t)t，尖角，不计圆角 |
| | 圆钢 / 方钢 | A=πD²/4 / a² |
| 围护板（6） | 压型单板 | kg/m²=t·ρ·dev/eff（展开/有效宽度由用户按板型资料填，不内置板型库） |
| | 金属夹芯板 | 上、下面板各按 t·ρ·dev/eff，加芯材 tc·ρc |
| | 玻璃钢采光板 | t·ρ·dev/eff，ρ 由用户填 |
| | 直立锁边板 | 同压型单板，另加用户填的附加 kg/m² |
| | PC阳光板 | 厂家面密度×面积（不用板厚×密度估算） |
| | 天沟/泛水 | dev·t·L·ρ |
| 曲线构件 | 半径+圆心角 / 弦长+矢高 | L=Rθ；R=(c²/4+f²)/(2f)；重量=弧长×kg/m |
| 螺栓抗滑移 | — | Nv=0.9·k·nf·μ·P；N/(n·Nv) |
| 楼梯梯段 | — | 总高/级高须整除（不取整）；水平跨 L=(n−1)b；M=wL²/8；δ=5wk·L⁴/(384EI·cos²θ)（垂直梯梁方向，不计轴力） |
| 栏杆 | — | 扶手简支 M=qs²/8、δ=5qs⁴/(384EI)；立柱悬臂 P=qs、M=P·Hp、δ=P·Hp³/(3EI) |
| 组合视图/DXF | — | 侧立面线框（踢面、踏面、踏步前缘线、扶手、立柱），导出 R12 风格 ASCII DXF（LINE，图层 STAIR/RAIL） |

结果区是可选中的表格，“复制结果”输出制表符分隔文本（名称/数值/单位/说明）。
