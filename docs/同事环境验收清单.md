# 同事环境验收清单（待完整开发交付后执行）

按用户安排，本清单留待完整开发后，由同事在独立 Windows 环境验收。当前不是已执行记录。验收时记录 EXE 版本、SHA256、Windows 版本、显示缩放、打印机与实际结果，不使用旧业务工程对算。

## 启动与数据保存

- 仅复制待验收主 EXE，不复制开发 Qt DLL、插件或 assets；无 Qt 开发环境、无登录、无安装条件下双击运行。
- 首次进入空白工程；确认没有历史业务项目。使用合成数据新建工程、父子构件和零件。
- 保存到中文路径，关闭并重开，核对层级、数量、材质、规格、人工覆盖与系数快照。
- 更改企业自定义数据后重启，确认持久保存。升级后检查工程、企业数据、设置仍保留。
- 不可写目录应显示清楚错误，不应丢失当前录入。

## 录入与计算

- 测试构件/零件创建、编辑、复制、删除、层间复制、粘贴预览、列设置和行移动。
- 标准版次区分、规格搜索、长度 mm→m、数量及父构件倍数；面密度项需宽度。
- 非标六类几何、非法尺寸、未知规格、缺面积系数应明示；不得默默算零。
- 采用结果并实时联动、切行停止旧行回写、人工覆盖保护、解锁和撤销。
- Q355 材质选择与旧前缀兼容；此软件不替代强度设计验算。

## 界面和报表

- 100%、125%、150% 显示缩放；常用分辨率下工具栏、表格、更新区可操作。
- 浅色/深色图标与皮肤、中文字体、四页离线帮助；断网仍能计算。
- 汇总、全部报表；Excel 三张表实际打开核对内容与合并单元格。
- PDF 实际逐页检查文字、分页、表头、金额/重量/面积列；打印预览及打印机实际打印。

## 更新（待模块交付后）

使用专用合成发行环境与测试签名，不使用真实工程。由发布者提供可信配置与发行材料。

- 未配置源时明确显示未配置；断网、超时、HTTP错误、无新版本均有准确状态。
- 合法签名的新版可下载；篡改清单、错公钥、错哈希、截断文件、非HTTPS地址拒绝安装。
- 录入过程中不强制退出；安装前保存提示。退出后替换、重启和成功确认。
- 下载失败、权限不足、旧进程不退出、重启失败可恢复；确认旧 EXE 和用户资料未丢失。

每项标通过/失败/未测，失败留截图及日志。人工验收签字、日期和计算样例另存，不把本清单当作通过证明。906 条缺面积及181组历史系数冲突是交接基线边界，需单列数据问题，不用未定义面积的条目作完整重量/面积通过样例。
