# 原生表格 v1.0.3 迁移副本

本目录来自交接指定的 steeltally-v1.0.3 工作区。迁移保留完整 table_qty 源码、图标、皮肤、统一型材库、定额参考、类型目录及通用测试工具。新建、打开、保存工程以及现有表格、构件、计算、报表功能均保留。

## 目录

- table_qty/src：完整原生 C++ / Qt 源码。
- table_qty/assets：通用资源与公共数据。
- table_qty/tests/fixtures：观察得到的通用目录资料，不含旧业务工程。
- table_qty/tools：通用维护和验证工具。compare_calculations.py 是可复用比较工具，没有迁入其旧工程输入或对算结果；verify_delivery.py 是历史集成验证工具，需要旧部署证据，不作为独立版验收命令。
- backup-original/data：仅保留合库脚本依赖的两份公共型材输入，不作为第二套活动型材库自动导入。
- merge_catalogs.py / catalog-merge-report.json：合库逻辑和冲突记录。
- build-native.ps1：独立原生动态 Qt 构建入口，使用新建 ASCII 临时目录进行编译，防止中文路径 MOC 错误；只在成功后发布到 build。重复构建会将原 build 归档至“旧版可删”。
- verify-native.ps1：运行原生计算和交互自测，退出码与日志存入 verification 下的新目录，使用隔离的合成用户数据。
- docs/migration-manifest.json：复制时逐文件 SHA256 与排除记录。

原工作区、桌面部署版和历史工程均保留原状。未复制原工作区的旧 build、portable、回归输出、已部署记录、历史对算结果及旧源码备份。未迁入任何用户旧工程或企业自定义覆盖数据。今后创建的工程仍可自行保存并打开。

## 构建与验证

在 PowerShell 中运行目录根部 build-native.ps1，再运行 verify-native.ps1。默认工具链为 C:\Qt\6.8.3\mingw_64 和 C:\Qt\Tools\mingw1310_64，可通过构建参数指定。当前产物仍动态链接 Qt DLL 与插件，但 2,623 个图标、皮肤、帮助与公共数据文件已经通过 resources.qrc 内嵌，运行和计算自测统一使用 :/assets，不再读取外部源码资源。源码 assets 目录用于后续维护与重建。

verify-native.ps1 -Isolated 会建立没有 assets 的新运行目录，部署 Qt DLL 及插件，并移除 PATH 中的开发工具路径后自测；这是本机隔离验证，不等同于独立 Windows 环境验收。

当前保持应用版本 1.0.3 和既有计算逻辑；窗口标题统一读取应用版本。帮助菜单包含使用说明、计算依据、更新日志与关于。工具栏右侧显示版本及“未配置更新源”；当前检查按钮仅提示配置状态，尚不执行下载或替换。

当前还不是最终免安装单文件 EXE。qrc 资源内嵌已实施并通过隔离自测；静态 Qt、独立 Windows 环境验证、更新模块及对应许可材料仍需后续实施。内置库缺失面积及系数冲突不因迁移消失，不应把自测通过视作全部标准数据准确认证。
