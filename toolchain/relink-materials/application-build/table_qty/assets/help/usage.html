使用说明

工程

启动进入空白工程。使用工具栏新建、打开、保存工程；工程保存为 JSON。示例工程为内置合成演示，须手动载入。退出或更新前请先保存当前工作。

录入与计算

选择构件类型并新建构件，添加零件，填写规格、长度、数量和材质。长度单位为 mm。型材查询/计算支持标准件与非标参数；采用结果前核对规格、标准版次和面积口径。

实时联动

采用结果并开启实时联动后，修改当前行参数会更新计算。切换零件行后旧行联动停止。人工覆盖值受保护，可显式解锁；撤销本次计算入口保留。

汇总与导出

构件数量及父构件倍数参与汇总。切换汇总和报表页检查结果；导出 Excel 为三张合并工作表，PDF 包含全部报表。缺少计算数据时应先补齐。

数据保存

公共库随程序内嵌。企业覆盖数据保存在 EXE 同级 user-data，或通过 --data-root 指定目录；升级必须保留。工程请保存到可写目录并定期备份。

快捷操作

表格原有编辑、粘贴、行移动、列设置与层间复制入口均保留。不同控件的快捷行为依焦点而定。
